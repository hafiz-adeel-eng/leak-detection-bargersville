# AI images

Generate each image with Midjourney, ChatGPT (DALL·E), Ideogram or Gemini, export as **WebP**
(under ~150 KB) and save it here with the **exact file name** shown. The site picks each one up
automatically on the next build; until then it shows the built-in illustration or leaves the slot out.

Shared style: navy work uniforms, teal and amber accent light, real Midwest/Indiana homes,
photorealistic, no text or logos.
